# Лабораторная работа №6

## Структура проекта

- `part1_VeeValidate` — форма регистрации с валидацией данных через VeeValidate и Yup.
- `part2_Routing` — TodoList с использованием Vue Router и LocalStorage.
- `part3_Pinia` — TodoList с управлением состоянием через Pinia.

## Запуск проекта

Для запуска нужной части необходимо перейти в соответствующую папку и выполнить команды:

```bash
npm install
npm run dev
```
