# Лабораторная работа №5

- `part1` — Toolkit, PixiJS, Axios, Postman
- `part2` — Vue Introduction
- `part3` — Advanced Vue

## Part 1. Toolkit, PixiJS, Axios, Postman

Материалы Postman находятся в папке `part1/postman`.

### Запуск

Установка зависимостей:

```bash
cd part1
npm install
```

Запуск локального сервера:

```bash
npx http-server . -p 5500
```

Открыть PixiJS-анимацию:

```text
http://localhost:5500/pixi-animation.html
```

Открыть Axios-запросы в браузере:

```text
http://localhost:5500/axios-browser.html
```

Запуск Axios-запросов через Node.js:

```bash
node axios-node.js
```

## Part 2. Vue Introduction

### Запуск простого кликера

Открыть файл:

```text
part2/simple-clicker.html
```

### Запуск Vue-проекта

```bash
cd part2/vue-clicker-project
npm install
npm run dev
```

После запуска открыть адрес, указанный в терминале.
